# 話者判別の課題と検証 — 切り抜き制作を支えるために

## 何を解決したいか

複数人の会話を日本語の字幕にするときは、「何と言ったか」だけでなく「誰が言ったか」も大切です。声が重なると片方の発話が抜けたり、別の人の発言として表示されたりします。私は海外の配信の切り抜き制作で、このような問題に関心を持ち、AIを活用した制作・確認の改善に取り組んできました。

ここでは、私が制作の中で行った確認と判断、AIが担当した試作・検証を紹介します。このリポジトリは話者判別モデルや研究用データを収録しておらず、以下の研究結果をこのリポジトリだけで再現することはできません。

## 私が行ったこと

- **自分の耳で確認する**：話者の聞き分けに取り組み、25問の試行に回答し、集計を依頼しました。自分の回答も訂正や確認が必要になり得るため、これだけで独立した正解データや判別精度の証明にはなりません。
- **確認方法を考える**：毎回すべてを自分で判断する負担を踏まえ、機械が付けた候補を人が確認する方法を提案しました。
- **扱う情報の条件を決める**：声紋モデルの利用は認めつつ、音声を外部に送らない方針を伝えました。
- **制作を止める判断をする**：2026年10月、話者判別がうまくいかない組み合わせについては、制作途中のものを含め、動画制作を停止する方針を伝えました。判別の問題が未解決のまま制作を進めるのではなく、扱いを見直した例です。

この経験で私が担ったのは、制作上の問題を確かめ、必要な確認や条件を伝え、方針を判断することです。話者判別の仕組みや試作用コードの設計・実装、既存モデルを使った処理、下記の比較・集計はAIエージェントが担当しました。確認に取り組んだことと、本人がモデルを独力で実装できることは別です。

## まず分けて考える問題

| 処理 | どんな問いに答えるか | それだけでは分からないこと |
| --- | --- | --- |
| 音声認識 | 何と言ったか | その言葉を誰が言ったか、重なった声を全て拾えたか |
| 話者区間推定（ダイアライゼーション） | 話者A、Bがいつ話したか | A、Bが実際には誰か |
| 話者照合 | 声の候補と人物を結び付けられるか | 候補外の人や録音条件の違いを含めた正しさ |
| 字幕への反映 | 発話と表示をどの時刻につなげるか | 内容や話者の判断が正しいか |

匿名IDは処理のための記号であり、人名ではありません。区間推定は、混ざった音声から各人の波形を取り出す音声分離とも別の処理です。短い発話、複数人の同時発話、よく似た声や録音環境の違いでは、判断が難しくなります。

## 非公開の試作から分かったこと

2026年10月、AIエージェントが制作の確認を補助する**読み取り専用の試作画面**を作りました。保存済みの一つの視点の音声に対し、既存の話者区間推定モデルで得られた匿名区間を字幕の時刻に重ね、候補を表示するものです。人物名の自動確定や制作物への自動反映は行っていません。

この試作では、字幕行と匿名区間を結び付ける計算について別のコードで照合しました。ただし、**時刻の対応が計算どおりであることと、モデルの話者区間が正しいことは別**です。対象音声での実発声者の正解、区間推定の正答率、元配信時計との独立した対応は検証されていません。短い接触でも候補として表示するため、候補の表示数を正解数として扱えません。

例えば、以下は実データではない架空の区間です。AとBが3〜4秒で重なっていることは分かりますが、それぞれが誰で、何を言ったかはこの表からは決まりません。

| 匿名の候補 | 開始 | 終了 |
| --- | ---: | ---: |
| A | 1秒 | 4秒 |
| B | 3秒 | 5秒 |

## 補足：AIによる公開データでの比較

制作音声で人物を確定する評価とは別に、AIエージェントが公開データセット [VoxConverse](https://www.robots.ox.ac.uk/~vgg/data/voxconverse/) の既使用18録音を使い、匿名話者の区間をつなぐ方式を比較した記録があります。正解を使わずに候補を固定してから、既存の正解ラベルと照合した検証です。

| 比較した方式 | 話者区間の誤り率（micro DER） | 読み方 |
| --- | ---: | --- |
| A：既存の基準 | 11.454% | 採用可否を決める基準 |
| B：別の既存方式 | 14.059% | 再連結前の比較対象 |
| C：新しい再連結方式 | 12.411% | Bより改善したが、基準Aより悪化 |

DERは発話の見逃し、余分な発話検出、話者の取り違えを発話時間に対してまとめた指標で、小さいほど誤りが少ない値です。この評価では重なりも含め、境界の猶予を設けていません。CはBより改善しましたが、基準Aと比べて話者の取り違えが約70秒増え、事前に設定した削減目標を満たさなかったため不採用となりました。これは**同じ18録音内の診断**で、未使用の録音に対する独立評価や、配信中の人物名の正答率ではありません。

検証は保存済みの予測と特徴量を用いたもので、新たなモデル学習の成果ではありません。評価対象の音声・正解・予測・実験コードは本リポジトリには収録していないため、数値は非公開記録に基づく参考結果です。公開データの名称は出典の説明であり、元データの再配布許可を意味しません。

## 次の課題

1. 利用・公開条件を確認できる音声と、各時刻の話者を独立に確認した正解を用意する。
2. 同時発話・短い発話・雑音などの条件を分け、誤った人名の付与、判定保留、見逃しを別々に数える。
3. 開発に使っていない録音で再評価し、字幕確認を助ける効果と限界を確かめる。
4. 私自身が小さな処理を実行・変更・説明できるようになり、実際に行った学習や作業だけを記録する。

これらは今後の課題であり、実施済みの成果ではありません。
